# mod-weather — погода контекста для Claude Code

Мод для [Claude Code](https://code.claude.com), который показывает над полем ввода одну строку: насколько заполнен контекст сессии, сколько израсходовано лимитов, сколько стоила сессия и сколько ещё проживёт кеш. Заполнение контекста подаётся как погода: чем ближе к пределу, тем «хуже погода» и тем ярче цвет.

```
☂ Дождь ███████░░░░░ 62% · 124k/200k 5ч 64% неделя 31% $1.42 кеш: ещё 38 мин ×
```

Зачем: длинная сессия незаметно подходит к пределу контекста, а после паузы больше часа следующее сообщение заново читает весь диалог по полной цене. Строка показывает и то и другое заранее, не отрываясь от набора текста.

## Установка

В терминале, в сессии Claude Code:

```
/plugin install context-weather --marketplace Nugnii/mod-weather
```

Ответьте `y` на вопрос «Add marketplace?», затем выберите область (по умолчанию — для пользователя, во всех сессиях). Строка появится сразу, без перезапуска.

Из командной строки:

```bash
claude plugin install context-weather --marketplace Nugnii/mod-weather
```

В приложении Claude (вкладка Code), где `/plugin` не работает: **+** рядом с полем ввода → **Plugins** → **Add marketplace** → `Nugnii/mod-weather` → **Add plugin**. Мод, установленный из терминала для пользователя, работает и в приложении.

## Что в строке

| Элемент | Что значит |
| --- | --- |
| `☂ Дождь` | Погода по заполнению контекста, цвет полосы тот же |
| `███████░░░░░` | Полоса заполнения контекста |
| `62% · 124k/200k` | Процент и токены: занято / размер окна |
| `5ч 64%` · `неделя 31%` | Израсходовано пятичасового и недельного лимита; оранжевым от 80%. Окно лимита под другим именем показывается под своим именем |
| `$1.42` | Стоимость сессии по оценке `/cost` |
| `кеш: ещё 38 мин` | Сколько осталось жить кешу; красное `кеш остыл`, когда истёк |
| `×` | Скрыть строку; вернуть — командой `/weather` |

### Шкала погоды

| Заполнение | Погода | Цвет |
| --- | --- | --- |
| до 20% | ☀ Ясно | зелёный |
| 20–40% | ⛅ Малооблачно | синий |
| 40–55% | ☁ Облачно | обычный |
| 55–70% | ☂ Дождь | оранжевый |
| 70–85% | ⚡ Гроза | красный |
| от 85% | ⚠ Пора сжимать | красный |

На «Пора сжимать» стоит сделать `/compact`, пока модель ещё видит весь диалог.

### Предупреждение об остывшем кеше

Если кеш истёк, первое нажатие Enter сообщение не отправляет. Над строкой появляется карточка:

> Кеш, скорее всего, остыл: с последнего ответа прошло 61 мин. Это сообщение заново прочитает весь диалог, около 96k токенов. Нажмите Enter ещё раз, чтобы отправить.

Текст остаётся в поле ввода, второй Enter в течение двух минут отправляет его. Команды (`/compact` и другие) и сообщения с картинками проходят без задержки.

## Ограничения

- Время кеша — оценка мода. Он отсчитывает его от каждого запроса основной сессии к модели, срок (5 минут или 1 час) берёт из ответа API. Служебный запрос движка может продлить кеш незаметно, тогда «остыл» покажется раньше времени. Отсюда «скорее всего» в предупреждении.
- До первого ответа модели после установки вместо цифр стоит `—`, а времени кеша нет.
- Лимиты — те окна, которые прислал последний ответ API (подписка Claude). Какое окно API не прислал, того в строке нет; при работе по API-ключу лимитов нет совсем.
- API модов Claude Code пока в раннем доступе и может меняться между версиями. Мод проверен на Claude Code 2.1.330.

## Разработка

```bash
git clone https://github.com/Nugnii/mod-weather && cd mod-weather
claude plugin validate .   # манифест, модуль, маркетплейс
claude plugin test .       # тесты в tests/
claude --plugin-dir .      # сессия с модом из этой папки
```

Вся логика — в `hooks/register.tsx`, хранимые значения описаны в `types/index.d.ts`. Пороги погоды — в функции `weather()`.
