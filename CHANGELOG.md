## [0.2.0] - 2026-11-22

### Добавлено
- В предупреждении об остывшем кеше — стоимость перечитывания диалога по ценам Claude API и сравнение с тёплым кешем, например «≈ $3.44 (с тёплым кешем было бы $0.086)». Цена считается по модели сессии, сроку кеша (5 минут или час) и числу токенов.
- Гифка строки в начале README и раздел об экономии на остывшем кеше.

## [0.1.0] - 2026-11-22

### Добавлено
- Строка над полем ввода: погода по заполнению контекста (шесть уровней, от «Ясно» до «Пора сжимать»), полоса, процент и токены, все окна лимитов из ответа API (5ч и неделя — короткими именами), стоимость сессии, время жизни кеша.
- Предупреждение при остывшем кеше: первый Enter задерживает сообщение и возвращает текст в поле, второй в течение двух минут отправляет.
- Кнопка `×` скрывает строку, команда `/weather` возвращает её.
